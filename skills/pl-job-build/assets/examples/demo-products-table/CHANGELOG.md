# Changelog

All notable changes to this job are documented in this file. The format is based on Keep a Changelog.

## [1.0.0] - 2026-10-29

### Added

- First version of the example: schema import in `EXHAUSTIVE` mode and import of 20 demo products.
- Invented demo products: EAN-13 codes of the GS1 restricted-circulation range (prefix `200`), generic titles and descriptions, image and attachment values pointing to `https://example.com/...` placeholders.
- Job-level outputs exposing both import reports.
